# Environment Variables Guide
**MediFind – Phase 10: Production Deployment Preparation**

---

## 1. Overview

MediFind uses `python-dotenv` to manage application configuration. Settings are decoupled from source code and loaded from operating system environment variables or a local `.env` file during development.

---

## 2. Complete Environment Variables Reference

| Variable Name | Required | Default (Dev) | Production Example | Description |
|---------------|:--------:|:-------------:|--------------------|-------------|
| `DEBUG` | **Yes** | `True` | `False` | Disables debug mode and detailed tracebacks in production. |
| `SECRET_KEY` | **Yes** | Insecure default | `5xDi_3NW1-lVUd3_GIVc4IPOn-...` | Cryptographic signing key for sessions, CSRF, and cookies. |
| `ALLOWED_HOSTS` | **Yes** | `*` | `medifind.onrender.com,localhost` | Comma-separated list of valid domain names for Host header validation. |
| `CSRF_TRUSTED_ORIGINS` | **Yes** | Empty | `https://medifind.onrender.com` | Comma-separated list of trusted HTTPS origins for CSRF POST validation. |
| `DATABASE_URL` | Optional | Empty (SQLite) | `postgres://user:pass@host:5432/db` | Connection string for PostgreSQL. If omitted, uses local `db.sqlite3`. |
| `SECURE_SSL_REDIRECT` | Optional | `False` | `True` | Redirects all unencrypted HTTP traffic to HTTPS. |
| `SECURE_HSTS_SECONDS` | Optional | `0` | `31536000` | HTTP Strict Transport Security duration (1 year = 31536000s). |
| `EMAIL_BACKEND` | Optional | Console Backend | `django.core.mail.backends.smtp.EmailBackend` | Controls email delivery (console vs SMTP). |
| `PYTHON_VERSION` | Optional | System default | `3.11.9` | Instructs PaaS builder to use Python 3.11. |

## 3. Exact Commands for Windows Users (PowerShell)

### Inspect Current Environment
```powershell
Get-ChildItem env:
```

### Set Temporary Session Environment Variables
```powershell
$env:DEBUG = "False"
$env:SECRET_KEY = "your-generated-50-character-secret-key-here"
$env:ALLOWED_HOSTS = "localhost,127.0.0.1,medifind.onrender.com"
$env:CSRF_TRUSTED_ORIGINS = "https://medifind.onrender.com,http://localhost:8000"
$env:SECURE_SSL_REDIRECT = "False"
```

### Verify Environment Variable in PowerShell
```powershell
$env:DEBUG
$env:SECRET_KEY
```

### Delete / Reset Environment Variable in PowerShell
```powershell
Remove-Item env:DEBUG
Remove-Item env:SECRET_KEY
```

## 4. Production Cloud Setup (Render Dashboard)

When deploying to Render, environment variables are set in the **Environment** tab of the web service:

1. In the Render web dashboard, select your `medifind` service.
2. Navigate to **Environment**.
3. Confirm the following keys are populated:
   - `DEBUG`: `False`
   - `SECRET_KEY`: *(Auto-generated by Render blueprint)*
   - `ALLOWED_HOSTS`: `.onrender.com,localhost,127.0.0.1`
   - `CSRF_TRUSTED_ORIGINS`: `https://*.onrender.com`
   - `DATABASE_URL`: *(Linked automatically from `medifind-postgres`)*
   - `SECURE_SSL_REDIRECT`: `True`
   - `SECURE_HSTS_SECONDS`: `31536000`
4. Click **Save Changes**. Render will automatically redeploy with the updated environment.
